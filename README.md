# CALVINE Bot

Готовая версия на базе загруженного пользователем проекта.

## Что добавлено

- Кнопка **💰 Депозит** в профиле `/p`.
- Пользователь сам вводит сумму депозита.
- Бот создаёт счёт CryptoBot на введённую сумму.
- После оплаты бот автоматически проверяет статус платежа.
- Оплаченный депозит записывается в профиль вместе с датой.
- Повторная обработка одного invoice защищена таблицей `payment_events`.
- Уведомление приходит в группу, где пользователь оформил депозит.
- Уведомление также отправляется в `ADMIN_CHAT_ID`.
- Пользователю отправляется личное подтверждение, если он уже запускал бота.
- Существующая команда `/deposit @username сумма` сохранена для администратора и теперь тоже записывает дату.

## Переменные окружения

Обязательные:

- `BOT_TOKEN` — токен Telegram-бота.
- `CRYPTOBOT_API_TOKEN` — токен Crypto Pay API.

Для уведомления администратора:

- `ADMIN_CHAT_ID` — Telegram ID личного чата администратора.
  Можно указать несколько ID через запятую.

Необязательные:

- `DB_PATH` — путь к SQLite. По умолчанию `/var/data/reputation.db`.
- `DEPOSIT_ASSET` — валюта CryptoBot. По умолчанию `USDT`.
- `DEPOSIT_MIN` — минимальный депозит. По умолчанию `1`.
- `DEPOSIT_MAX` — максимальный депозит. По умолчанию `1000000`.
- `CRYPTOBOT_API_URL` — по умолчанию `https://pay.crypt.bot/api`.

## Как пользователь вносит депозит

`/p` → **💰 Депозит** → **💳 Внести депозит** → пользователь пишет сумму → бот создаёт CryptoBot invoice → пользователь оплачивает → через несколько секунд депозит появляется в профиле.

## Render

Если проект уже подключён к GitHub, достаточно заменить файлы проекта и убедиться, что установлены зависимости из `requirements.txt`.

Команда запуска:

```bash
python main.py
```

SQLite лучше хранить на persistent disk, если данные должны переживать перезапуск.

## Важно

Не записывай `BOT_TOKEN` и `CRYPTOBOT_API_TOKEN` в `main.py` или GitHub. Храни их только в Environment Variables / Secrets на Render.

CryptoBot используется через официальный Crypto Pay API. Проверка оплаченных счетов выполняется polling-механизмом раз в 10 секунд, поэтому подтверждение обычно приходит с небольшой задержкой.

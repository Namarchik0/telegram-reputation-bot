# CALVINE Bot v8

## Что добавлено
- В профиле больше нет кнопки «Депозит».
- В главное меню `/start` добавлена кнопка «🛒 Покупка».
- Меню покупок: Префикс, Модератор, Реклама.
- Реклама разбита на автопостинг, ОП и закреп.
- После выбора фиксированной цены бот автоматически создаёт Crypto Pay invoice.
- Для RUB/USD используется `currency_type=fiat`, поэтому цена счёта фиксирована в рублях или долларах, а оплатить его можно поддерживаемой криптовалютой.
- После оплаты бот фиксирует покупку и уведомляет пользователя/администратора.
- Депозит продолжает работать отдельно через меню «💰 Депозит».

## Переменные окружения
- `BOT_TOKEN` — токен Telegram-бота.
- `CRYPTOBOT_API_TOKEN` — API Token приложения Crypto Pay.
- `ADMIN_CHAT_ID` — Telegram ID администратора; можно несколько через запятую.
- `DB_PATH` — путь к SQLite, по умолчанию `/var/data/reputation.db`.
- `DEPOSIT_ASSET` — криптовалюта депозита, по умолчанию `USDT`.
- `DEPOSIT_MIN` — минимум депозита, по умолчанию `1`.
- `DEPOSIT_MAX` — максимум депозита, по умолчанию `1000000`.
